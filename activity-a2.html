Wie spielt man?

Die Klasse spielt in Teams. Eine Person bekommt einen Begriff aufs Handy – nur sie sieht ihn. Sie erklärt ihn, zeigt ihn als Pantomime oder malt ihn an die Tafel. Ihr Team rät. Jeder richtige Begriff bringt einen Punkt.

Spiel starten

Eigenen Kurs-Code eingeben (4 Ziffern, z. B. immer derselbe für deinen Kurs) – oder leer lassen, dann wird ein Code erzeugt. Gibt es den Code schon, öffnet sich das laufende Spiel.
